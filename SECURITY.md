# Security and privacy

Report suspected vulnerabilities privately to support@mubboo.flights. Include a minimal reproduction without credentials, passenger identities, payment details or private account data. Do not post sensitive reports in public issues.

These examples need no credentials. They connect only to the fixed public Mubboo endpoint and never read local browser sessions, environment tokens or account configuration. The optional demo uses fictional trip inputs and does not open a search link.

The hosted service's production implementation is outside this repository. See https://mubboo.flights/privacy and https://mubboo.flights/terms for the live service.
